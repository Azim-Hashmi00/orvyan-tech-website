# Orvyan Tech website

Static site (no build step). Hosted on Netlify.

- `index.html` – the whole home page. Content is plain HTML, edit it directly.
- `styles.css` – all styles.
- `privacy-policy.html`, `terms-of-service.html` – legal pages (same styles).
- `logo.svg` / `favicon.svg` – the logo mark. `logo.png`, `favicon.ico`, `favicon-16x16.png`, `apple-touch-icon.png`, `og-image.png` are exported from it.

## Common edits
- **Add a price:** in `index.html`, in the Pricing section, replace `Quoted after your free consultation` inside each `.plan`.
- **Add real client work:** the "Systems we build" section describes typical workflows. Replace it with real case studies (screenshots and client names only with permission).
- **Add testimonials:** only add real, attributable ones.
- **Contact form:** posts to Formtorch (`formtorch.com/f/t2vo9j93fa`), unchanged.
